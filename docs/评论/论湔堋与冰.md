# 论湔堋与冰

**都江堰最令人敬畏之处，不在于其屹立千年，而在于它要求后世不断岁修。**

**它不允许人只感动、不作为。**

**不允许人只歌颂、不继承。**

**更不允许为了眼前的热闹，而去动摇那套最初的取舍与秩序。**

　　

李冰治堰，先为后世设禁，并未止于一时之功。他立三石人为则，刻水位于石，明示进退之界。水至则安，过界即患。

> 大明天启年修《成都府志》云：又灌县斗鸡台之下，錾凿石崖，尺为之画，凡一十有一，谓之“水则”。水及其九，则民喜；尽没其画，则民困；皆秦蜀守李冰所为。**神智苦心，后莫敢违，而违之辄病**，此不可不知也。

所谓“与江神要”，非事鬼神，实是立法于江，使后人知所守、知所畏。自此之后，治堰者但有懈怠，水必以患应之，无可推诿。

此非神罚，乃法在也。



　　

其制非一役之功，乃累世相承之法也。 

自宋而后，岁修有定，官民共守。凡江势稍异、沙淤稍积，必按期疏治，不敢因循。宋人谓之“岁修”，以常治防大患，此制遂为定例。

及大明一统，诏定堰制，申明旧章，列为不易之法。凡守蜀者，皆以修堰为首务，不得以军政繁重而废水利之修。于是岁修之例，遂由成法而为国典。

洎乎近世，政体虽更，而其法不废。仍循旧制，约以五岁一大修，十岁一特修，以应江情之变。名目虽新，而精神实承宋明之旧贯也。

是以都江堰之所以久存者，非石坚木固，乃制度不坠。 其所以泽被千载者，非偶然之幸，实代代守法而不敢废也。





这就是一种“漢道”之智。

以自身为本，以现实为据，以后世为度。

先立根干，而后枝叶自生。

不逐浮名，不事虚功，但问——

可真护住了此脉？



曾经有人问为什么漢服近年突然复兴？

我回答到，那是因为人们终于意识到我们的文明仍然千疮百孔，文化曾被断代，史书曾被篡改，炎黄血脉曾被嘲讽与压迫。可它始终没亡，每代都有人不甘，不屈，不跪。

所以现在，我们正在重新接上那条被割断的衣冠文脉，在让華夏文明往前走。

毕竟文明不是靠掌声活着的，是靠人真正活着的。



岷江里的泪， 也从不是什么单纯的感动，而是**人忽然意识到，自己正站在一条仍然活着的文明根基之上**。

所以我敬李冰，亦不止敬其一人。

我所敬者，乃此一脉相承之道，此一以身当责、以久为期之民族心性。

这条江之所以不断，是因为始终有人肯守。这套法之所以未坠，是因为始终有人认得祖先的根。

若有一日，连这点自知、自守、自重都弃之不顾，纵使山河尚在，水声犹急，亦不过空流耳。

是以立于岷江之畔，所感者不独为冰公一人，是为此千载以来，仍肯为子孙修堰护源而不肯让根本旁落的民族。

能记得从何处来， 能分清什么不可让，能一代一代接过这份沉重而清醒的责任——

这便是漢之所以为煌煌之漢，亦是我等愿以终身守望灯火不熄之神州。


（注：皇也，煌也，大也，光华也。若九天银河流转，朗照我泱泱华夏。）
